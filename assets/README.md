# Assets

Drop the official Kern CCD wordmark and any other district visual assets here:

- `kccd-wordmark-light.png` — black wordmark on transparent, for the light header.
- `kccd-wordmark-dark.png` — white wordmark on transparent, for any dark band you add.
- `kccd-monogram.svg` — square monogram for favicons and small contexts.
- `favicon.ico` — site favicon (auto-served by GitHub Pages from the repo root).

The dashboard's sidebar currently uses a stylized chart-icon placeholder. Drop a real wordmark in and update `index.html`'s `.sidebar-logo` block to reference it.
